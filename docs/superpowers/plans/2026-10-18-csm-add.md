# `csm add` Implementation Plan

> **For agentic workers:** REQUIRED SUB-SKILL: Use superpowers:subagent-driven-development (recommended) or superpowers:executing-plans to implement this plan task-by-task. Steps use checkbox (`- [ ]`) syntax for tracking.

**Goal:** A repo-only admin CLI `csm` (new workspace `cli/`) whose first verb, `csm add`, takes one iReal Pro song all the way to a library chart: import, header flags, analysis saved, gaps checked, `make golden`, `make og`.

**Architecture:** The engine gains one pure export, `prepareChart`, that does the chart-side work (header overrides, analysis saved, gaps, advice, ambiguities). `cli/` parses arguments (`node:util` `parseArgs`) and sequences steps through injected effects (fs, `make`, output), so the sequence is unit-tested without touching disk. `main.ts` wires the real effects; `bin/csm.mjs` runs it through `vite-node`.

**Tech Stack:** TypeScript strict, Node 24, vitest 5, vite-node 6, npm workspaces, eslint (`@nuxt/eslint-config` standalone).

**Spec:** `docs/superpowers/specs/2026-10-18-csm-add-design.md`

## Global Constraints
- `cli/` is private, dev dependencies only; it imports only `@chord-scale-maker/engine` (public API) and `node:*` (tests may also import the engine's test helper `engine/src/ireal/__tests__/link.ts` by relative path).
- Engine stays free of Vue/DOM; `prepareChart` is pure (the date is a parameter).
- Exit codes: 0 done; 1 bad input, refused overwrite, gaps, or a failed step; 2 usage.
- Charts are written to `engine/charts/<slug>.txt`; never overwrite without `--force`.
- `engine/src/__tests__/api.test.ts` snapshot changes by exactly one name: `prepareChart`.
- Commits end with `Co-Authored-By: Claude Opus 5.5 <noreply@anthropic.com>`; stage files by name, never `git add -A`.

## Review Focus
1. Input is a file path that doesn't exist or isn't iReal → exit 1 with `can't read <path>` / the decode error, nothing written (Task 3 test).
2. Title with no ASCII letters (`東京`) → exit 1 with the `saveName` error, nothing written, even with `--print` absent (Task 3 test).
3. `--song` given a flag (`--song --print`) or `--kind` given anything but tune/form/exercise → usage error, exit 2 (Task 2 tests).
4. A header flag with an empty value (`--composer ""`) → treated as not given, not written as `composer: ` (Task 1 test: empty overrides are skipped).
5. `make golden` succeeds but `make og` fails → exit with og's code, advice not printed as if done (Task 3 test).

import { type MetaKey, parseChart, serializeChart } from './chart'

  return { chart: serializeChart(saved), gaps: tuneGaps(saved), advice: tuneAdvice(saved), ambiguities: ambiguities(analysis) }
}

```ts
import { parseArgs } from 'node:util'
import type { IRealPlaylist } from '@chord-scale-maker/engine'

export type HeaderFlag = 'composer' | 'form' | 'style' | 'kind' | 'aka' | 'recording' | 'source'
export const HEADER_FLAGS: readonly HeaderFlag[] = ['composer', 'form', 'style', 'kind', 'aka', 'recording', 'source']
const KINDS = ['tune', 'form', 'exercise']

export type AddArgs = Readonly<{ input: string; list: boolean; song?: string; force: boolean; print: boolean; overrides: Readonly<Partial<Record<HeaderFlag, string>>> }>

export const USAGE = [
  'usage: csm add <irealb:// link | export.html> [--list] [--song <n | title>] [--force] [--print]',
  '               [--composer …] [--form …] [--style …] [--kind tune|form|exercise] [--aka …] [--recording …] [--source …]',
].join('\n')

export function parseAddArgs(argv: readonly string[]): AddArgs | string {
  let parsed
  try {
    parsed = parseArgs({
      args: [...argv],
      allowPositionals: true,
      strict: true,
      options: {
        list: { type: 'boolean' },
        song: { type: 'string' },
        force: { type: 'boolean' },
        print: { type: 'boolean' },
        ...Object.fromEntries(HEADER_FLAGS.map((f) => [f, { type: 'string' as const }])),
      },
    })
  } catch (e) {
    return `${(e as Error).message}\n${USAGE}`
  }
  const { values, positionals } = parsed
  const input = positionals[0]
  if (input === undefined) return USAGE
  const song = values.song as string | undefined
  if (song !== undefined && song.startsWith('--')) return '--song needs a number or a title'
  const kind = values.kind as string | undefined
  if (kind !== undefined && !KINDS.includes(kind)) return `--kind is tune, form or exercise\n${USAGE}`
  const overrides = Object.fromEntries(HEADER_FLAGS.flatMap((f) => (typeof values[f] === 'string' ? [[f, values[f]]] : [])))
  return { input, list: !!values.list, ...(song === undefined ? {} : { song }), force: !!values.force, print: !!values.print, overrides }
}
```
`parseArgs` in strict mode throws for `--song --print` (an option value that looks like an option) and for unknown options; its message names the option, which the tests match. If a test fails only on message wording, keep `parseArgs`'s message and adjust nothing but the catch's prefix.

```ts
import { decodeIReal, irealToChart, prepareChart } from '@chord-scale-maker/engine'
import { type AddArgs, HEADER_FLAGS, type HeaderFlag, pickSong, saveName } from './args'

export type Effects = Readonly<{
  read: (path: string) => string
  exists: (path: string) => boolean
  write: (path: string, text: string) => void
  run: (target: 'golden' | 'og') => number
  out: (line: string) => void
  err: (line: string) => void
  chartsDir: string
  date: string
}>

/** the flag that fills a song page's gap, when there is one (`no composer:` → --composer) */
function gapHint(gap: string): string {
  const key = /^no (\w+):/.exec(gap)?.[1]
  if (key === 'composer') return `${gap} → --composer "…" (or --kind form|exercise)`
  return key && HEADER_FLAGS.includes(key as HeaderFlag) ? `${gap} → --${key} "…"` : `${gap} → edit the chart`
}

/** csm add (docs/superpowers/specs/2026-10-18-csm-add-design.md): one iReal song to a library chart; the exit code */
export function add(args: AddArgs, fx: Effects): number {
  let text: string
  try {
    text = /^irealb(ook)?:\/\//.test(args.input) ? args.input : fx.read(args.input)
  } catch {
    fx.err(`can't read ${args.input}`)
    return 1
  }
  const { value: playlist, diagnostics } = decodeIReal(text)
  for (const d of diagnostics) fx.err(`${d.fatal ? '✗' : '⚠️'} ${d.message}`)
  if (!playlist.songs.length) {
    if (!diagnostics.length) fx.err('no songs in it')
    return 1
  }
  if (args.list) {
    if (playlist.name) fx.out(playlist.name)
    playlist.songs.forEach((s, i) => fx.out(`${i + 1}. ${s.title}${s.composer ? ` (${s.composer})` : ''}`))
    return 0
  }
  const pick = pickSong(playlist, args.song)
  if (typeof pick === 'string') {
    fx.err(pick)
    return 1
  }
  const song = playlist.songs[pick]!
  const imported = irealToChart(song)
  for (const d of imported.diagnostics) fx.err(`⚠️ ${d.message}`)
  const p = prepareChart(imported.value, args.overrides, fx.date)
  const report = (): void => {
    for (const a of p.ambiguities) fx.err(`❓ ${a}`)
    for (const g of p.gaps) fx.err(`✗ ${gapHint(g)}`)
  }
  if (args.print) {
    fx.out(p.chart)
    report()
    for (const a of p.advice) fx.out(`· ${a}`)
    return 0
  }
  const named = saveName(song.title)
  if ('error' in named) {
    fx.err(named.error)
    return 1
  }
  const path = `${fx.chartsDir}${named.slug}.txt`
  if (fx.exists(path) && !args.force) {
    fx.err(`charts/${named.slug}.txt exists: --force to replace it`)
    return 1
  }
  fx.write(path, p.chart)
  fx.out(`📁 charts/${named.slug}.txt`)
  report()
  if (p.gaps.length) return 1
  for (const target of ['golden', 'og'] as const) {
    const code = fx.run(target)
    if (code !== 0) return code
  }
  for (const a of p.advice) fx.out(`· ${a}`)
  fx.out('next: review git diff engine/fixtures web/public/og, then commit the chart with them')
  return 0
}
```

import { spawnSync } from 'node:child_process'
import { existsSync, readFileSync, writeFileSync } from 'node:fs'
import { createRequire } from 'node:module'
import { dirname, resolve } from 'node:path'
import { add, type Effects } from './add'
import { parseAddArgs, USAGE } from './args'

/** csm <verb> …: the exit code (2: usage) */
export function main(argv: readonly string[], fx: Effects): number {
  const [verb, ...rest] = argv
  if (verb !== 'add') {
    fx.err(USAGE)
    return 2
  }
  const args = parseAddArgs(rest)
  if (typeof args === 'string') {
    fx.err(args)
    return 2
  }
  return add(args, fx)
}

const ENGINE = dirname(createRequire(import.meta.url).resolve('@chord-scale-maker/engine/package.json'))
const REPO = resolve(ENGINE, '..')

export const realEffects = (): Effects => ({
  read: (p) => readFileSync(resolve(process.cwd(), p), 'utf8'),
  exists: existsSync,
  write: (p, t) => writeFileSync(p, t),
  run: (target) => spawnSync('make', [target], { cwd: REPO, stdio: 'inherit' }).status ?? 1,
  out: (l) => console.log(l),
  err: (l) => console.error(l),
  chartsDir: `${ENGINE}/charts/`,
  date: new Date().toISOString().slice(0, 10),
})

if (process.env.CSM_MAIN === '1') process.exit(main(process.argv.slice(2), realEffects()))
