# Practice sheets at /song/<slug> Implementation Plan

> **For agentic workers:** REQUIRED SUB-SKILL: Use superpowers:subagent-driven-development (recommended) or superpowers:executing-plans to implement this plan task-by-task. Steps use checkbox (`- [ ]`) syntax for tracking.

**Goal:** A library chart's practice sheets live at `/song/round-midnight`; old `/song?chart=round_midnight` links still work.

**Architecture:** `pages/song.vue` becomes `pages/song/[[slug]].vue` (optional param, one component for `/song` and
`/song/<slug>`). Two pure helpers in `utils/site.ts` map a chart's file name to its path and back. The page
`router.replace`s old and underscore addresses to the hyphen form. Every library chart's `/song/<slug>` is prerendered.

**Tech Stack:** Nuxt 4 (static prerender, Vercel), Vue 3, Vitest (`web/test/`), Playwright (`web/e2e/`).

**Spec:** `docs/superpowers/specs/2026-10-12-song-url-design.md`

## Global Constraints

- Slug in the path: hyphens for the file name's underscores, the same rule as `tunePath()` (`blue_trane` → `blue-trane`).
- `?mine=<id>`, `?new=1` and `#s=<payload>` stay on a bare `/song`.
- Practice sheets stay `noindex` and out of the sitemap; canonical is `canonicalUrl(route.path)` (self).
- Redirects are client-side `navigateTo(..., { replace: true })`, the hash kept.
- Pages run under the hashed CSP: no inline `<script>` of our own.
- No feature flag: this is an address change, not a feature.
- Run commands from `web/`: `npm test` (vitest), `npm run typecheck`, `npm run lint`, `npm run e2e` (build + Playwright; `npx playwright test <file>` after a build to rerun one file). Repo root: `make test`, `make lint`, `make e2e`.
- Stage files by name, never `git add -A`.

## Review Focus

1. `/song?chart=nope` (unknown legacy chart) → goes to `/`, as today, not a blank editor. (Task 2 e2e)
2. Library chart → "Save as a copy" (`?mine=`) on the same component → editor restarts on the copy, address `/song?mine=…`. (Task 3: existing `my-charts.spec.ts` cases, URLs updated)
3. Back button after a legacy redirect doesn't return to `/song?chart=…` (replace, not push). (Task 2 e2e)
4. An edited library chart opened from My charts lands on `/song/<slug>` and shows the saved version. (Task 3: `my-charts.spec.ts` visitor case)
5. A chart file name with a hyphen would break the round trip → a unit test fails on one. (Task 1)

`web/app/utils/site.ts`, replacing the `tunePath` block:

```ts
/** a chart's slug in an address: hyphens for its underscores, which search engines read as word breaks */
const pathSlug = (slug: string): string => slug.replaceAll('_', '-')

/** a chart's tune page (blue_trane -> /tunes/blue-trane) */
export const tunePath = (slug: string): string => `/tunes/${pathSlug(slug)}`

/** a library chart's practice sheets (blue_trane -> /song/blue-trane) */
export const songPath = (slug: string): string => `/song/${pathSlug(slug)}`

/** the chart's file name from an address's slug, hyphens or underscores (chart file names have no hyphens) */
export const chartSlug = (slug: string): string => slug.replaceAll('-', '_')
```

`web/app/utils/sitemap.ts`, replacing `tunePathsOf`:

```ts
/** every chart file's slug, from a listing of the engine's charts/ (the config can't load the library's #charts glob) */
export const chartSlugsOf = (files: readonly string[]): string[] =>
  files.filter((f) => f.endsWith('.txt') && !isSyncCopy(f)).map((f) => f.replace(/\.txt$/, ''))

/** every chart file's tune page */
export const tunePathsOf = (files: readonly string[]): string[] => chartSlugsOf(files).map(tunePath)
```
