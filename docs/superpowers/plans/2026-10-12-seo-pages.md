# Composer pages, scale pages, song preview images, IndexNow: implementation plan

> **For agentic workers:** REQUIRED SUB-SKILL: Use superpowers:subagent-driven-development (recommended) or superpowers:executing-plans to implement this plan task-by-task. Steps use checkbox (`- [ ]`) syntax for tracking. UI tasks: load the `interface-design` skill, follow `.interface-design/system.md`, and screenshot at 1280 and 390 px, light and dark. Engine tasks: TDD skill.

**Goal:** `/scales/<name>`, `/composers/<name>` (and their indexes), a committed link-preview image per song, and IndexNow pings after production deploys.

**Architecture:** pure engine functions (`scaleUsage`, `playsOver`, `composersOf`) feed prerendered content pages built from #200's components; a local Playwright script draws the preview images, checked fresh by a manifest test; a GitHub Actions workflow lists changed URLs and pings IndexNow.

**Tech Stack:** TypeScript (strict), Nuxt 4 (prerender), Vue 3, VexFlow (client), Playwright (scripts), GitHub Actions, Vitest.

**Spec:** `docs/superpowers/specs/2026-10-12-seo-pages-design.md` (issues #164–#167).

**Prerequisites (landed before this starts):** #198 (`/song/<name>` indexable, `songHead`), #200 (`SheetRail`, `ToggleButton`, paper/stand tokens, the library's phone list and `letterIndex`, content-page sticky index, `system.md`). Rebase on them; use their names.

## Global Constraints

- Prerendered pages; CSP unchanged; no third-party origins; no new runtime dependency (Playwright is already a dev dependency).
- Slugs: scales `key.replaceAll(' ', '-')`; composers ASCII-folded, lowercase, quotes dropped, non-alphanumerics → `-`.
- Composer credits split on `, ` and ` & `; `kind: form`/`exercise` charts have none.
- Tunes using a scale: Standard level, seed 0, at build time; list capped at 30.
- OG images: 1200×630 PNG, ≤ 60 KB each, `web/public/og/<name>.png`, `manifest.json` freshness hash.
- IndexNow: a non-2xx never fails the workflow; ≤ 10,000 URLs per ping.
- One PR per issue, in order #165 → #164 → #166 → #167, each `Closes #…`. `make test` after each task; `make lint`, `make e2e` before each PR. Commits end with `Co-Authored-By: Claude Opus 5.5 <noreply@anthropic.com>`; stage by name.

## Review Focus

- **Build time**: `scaleUsage` analyses 242 charts once per build, not per page — Task 1 memoises at module level; the PR states `nuxt build` time before/after.
- **Composer name variants** ("Duke Ellington" vs "Edward Kennedy Ellington", "Antonio Carlos Jobim" vs "A. C. Jobim"): one page per spelling as written; Task 3 Step 4 adds an `analyse` warning listing near-duplicate composer slugs (same surname, different given names) for the owner to normalise in the charts.
- **A scale nothing uses** (e.g. a bebop scale with no library tune at Standard): the Tunes section reads "No library tune plays it at the Standard level yet", not an empty list — Task 2 e2e.
- **Stale OG images after a chart edit**: the manifest test fails in CI — Task 6.
- **IndexNow on the first deploy** (no previous production deployment): ping the whole sitemap once — Task 7 test.

### Task 8: the key and the workflow

**Files:** Create `web/public/<key>.txt`, `.github/workflows/indexnow.yml`; Modify `docs/design.md` (§SEO).

- [ ] **Step 1:** generate the key (`openssl rand -hex 16`), commit `web/public/<key>.txt` containing it; check it's served (`make preview`, `curl -s localhost:3000/<key>.txt`).
- [ ] **Step 2:** workflow:
```yaml
name: IndexNow
on: deployment_status
permissions: { contents: read, deployments: read }
jobs:
  ping:
    if: github.event.deployment_status.state == 'success' && github.event.deployment.environment == 'Production'
    runs-on: ubuntu-latest
    steps:
      - uses: actions/checkout@v4
        with: { fetch-depth: 0 }
      - uses: actions/setup-node@v4
        with: { node-version: '24' }
      - run: npm ci --ignore-scripts
      - name: Previous production commit
        id: prev
        env: { GH_TOKEN: '${{ github.token }}' }
        run: echo "sha=$(gh api "repos/${{ github.repository }}/deployments?environment=Production&per_page=2" --jq '.[1].sha // empty')" >> "$GITHUB_OUTPUT"
      - name: Ping
        run: node web/scripts/indexnow-urls.mjs --from "${{ steps.prev.outputs.sha }}" --to "${{ github.event.deployment.sha }}" --ping || echo "::warning::IndexNow ping failed"
```
(Node 24 as `ci.yml`; match its `npm ci` flags and action versions.) The `--ping` mode POSTs `{ host: 'www.chordscalemaker.com', key, keyLocation: 'https://www.chordscalemaker.com/<key>.txt', urlList }` to `https://api.indexnow.org/indexnow` and logs the status.
