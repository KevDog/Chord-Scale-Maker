  1. 1One editor, the text, made smart. The grid goes; the text is coloured by part (section, bar, chord, scale, function, comment, directive), and an Insert menu writes @copy, @ending, @key, @segno, @nav lines from a small form, so nobody has to learn the syntax first.
  2. 2Problems at the line: a squiggle, a gutter mark, and a hover card with a fix (“Change to D7b9b5”), not a list under a 60vh box. The same card opens with the keyboard (F8).
  3. 3Completions after the chord's pipe: its scales from scaleChoices, with formulas; after the scale's pipe, its functions from functionChoices; after an @, the directives.
  4. 4Smart Enter: a new line starts with the section and the next bar (⇧↵ keeps the same bar, for a second chord). Renumber bars closes gaps after an insert or delete, and moves the directives with them.
  5. 5A status line reads the caret's row back in words: section, bar, chord, scale, numeral and why.
  6. 6Live preview beside the text (sticky, scrolled to the caret's bar) instead of 1,600 px below it.
  7. Hard parts. No CodeMirror (runtime dependencies are fixed), so colouring is a <pre> mirrored under a transparent <textarea>, and the completion list is placed by measuring the caret: fiddly with IME, wrapping, zoom and phone selection handles. And it keeps the bar-number format, so it smooths typing rows rather than removing them.
